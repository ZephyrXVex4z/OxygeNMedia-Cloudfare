Bienvenido a
OxygeNMedia

OxygeNMedia es una plataforma social y multimedia donde puedes compartir contenido, descubrir publicaciones y expresar tus intereses a tu manera.

¿Qué es OxygeNMedia?

OxygeNMedia busca reunir diferentes tipos de contenido en un mismo espacio. La plataforma está pensada para que las personas puedan compartir cosas que les interesan, descubrir contenido de otros usuarios y construir una experiencia personalizada.

En pocas palabras: OxygeNMedia es un espacio para compartir y descubrir contenido. Memes, información, música, publicaciones y mucho más pueden formar parte de la plataforma.

Tecnología detrás de OxygeNMedia

OxygeNMedia combina tecnologías web con diferentes servicios y APIs para proporcionar sus funciones.

Web

La plataforma está desarrollada principalmente utilizando HTML5, JavaScript y CSS.

Datos y almacenamiento

OxygeNMedia utiliza Firestore y Cloudflare R2 para gestionar información y archivos multimedia.

Música

Las integraciones con Spotify y Last.fm permiten incorporar información y funciones relacionadas con música.

IA y notificaciones

Gemini y OneSignal forman parte de las tecnologías utilizadas para determinadas funciones de inteligencia artificial y notificaciones.
